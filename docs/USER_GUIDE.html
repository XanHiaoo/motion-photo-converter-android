01

从视频生成动态图

截取一段视频，并从片段中挑选一帧作为封面。

操作步骤

  1. 选择视频：在首页点 视频生成动态图，选择 MP4 或 MOV。
  2. 设置片段：拖动时间轴两侧手柄调整起止点；按住选区内部可整体左右移动片段。靠近素材边缘拖动时，时间轴会跟随扩展。
  3. 选择封面：拖动 拖动选择封面 滑块，在已选片段内定位封面帧。
  4. 预览和渐变：点 预览片段 检查选段。结束时渐变回封面默认开启，时长为 0.5 秒；可调整或关闭。
  5. 选择裁剪方式：快速裁剪直接复制原视频，通常更快但起点可能略有偏差；精确裁剪重新编码 H.264，边界更准但处理更慢。
  6. 生成并保存：点 生成 Motion Photo，完成后点 保存 Motion Photo。Android 写入相册，Web 下载文件。

不调整选段时默认使用完整视频。封面保存为 JPEG。启用结尾渐变时优先处理视频结尾的短过渡；Android 设备会尝试硬件加速，不兼容时可能回退到软件处理。

02

批量转换动态照片

一次导入多张已有动态照片，逐项识别、转换或直接保存。

导入与处理

  1. 打开批量模式：在首页点 批量转换。
  2. 选择动态照片：点 选择动态图文件，在系统选择器中多选 JPG / JPEG / HEIC。稍后可点 继续添加文件 补充队列。
  3. 等待分析：每个文件需包含静态图片和内嵌 MP4 / MOV。普通静态图或缺少内嵌视频的文件无法按此方式转换，请改用 照片 + 视频。

识别状态

已是 Samsung Motion Photo

已符合目标格式，可直接点该行下载按钮保存。

已识别图片和视频

点该行的 转换，或点页面底部的 全部转换 顺序处理。

无法解析或转换失败

检查文件内容与格式；失败项会显示原因。普通静态图应改用照片 + 视频模式。

批量渐变：默认启用结束时渐变回封面，时长初始为 0.5 秒。设置会应用于随后转换的文件；处理期间请保持页面打开。

03

照片 + 视频合成

用一张照片作为封面，再把视频片段合成为动态照片。

操作步骤

  1. 打开合成模式：在首页点 照片 + 视频。
  2. 选择封面照片：点 选择照片，导入 JPG / JPEG / HEIC / PNG。所选照片会作为封面。
  3. 选择视频：点 选择视频，导入 MP4 / MOV。
  4. 按需适配尺寸：启用 图片自适应视频尺寸，可按视频宽高调整照片。
  5. 设置视频片段：在时间轴调整起止位置；拖动选区中间可整体横移，并点 预览片段 检查效果。
  6. 调整渐变和裁剪：结束时渐变回封面默认开启，时长为 0.5 秒。按需调整、关闭，或选择快速 / 精确裁剪。
  7. 生成并保存：点 生成 Motion Photo，完成后保存结果。

未裁剪时使用完整视频。此模式没有单独的视频封面滑块，因为所选照片始终作为封面。

▣

隐私与兼容性：文件在本机读取和处理，不会上传；原始文件不会被覆盖。Android 输出到 Pictures/Motion Photo Tool，Web 版通过浏览器下载。Android 最低支持 Android 10；较新的 System WebView 有助于视频处理。

遇到问题时

批量文件无法识别
确认原文件同时包含图片和内嵌 MP4 / MOV。普通静态照片请改用照片 + 视频模式。
照片或视频无法预览
优先尝试 JPEG 和 H.264 MP4。MOV 需要先转换，可能花费更长时间。
快速裁剪边界不准
改用精确裁剪。重新编码会更慢，长视频请耐心等待。
处理似乎停住
保持应用或标签页打开。大文件或 MOV 处理时间较长。
相册中找不到结果
检查 Pictures/Motion Photo Tool，或在文件管理器搜索最近生成的 _MP.jpg。
生成后不能播放
不同机型和图库对编码的支持不同。改用 H.264 MP4、缩短片段后重新生成。
