# Motion Photo Tool 使用指南

Motion Photo Tool 可从视频制作 Samsung Motion Photo、批量转换已有动态照片，或将照片与视频合成为动态照片。所有媒体处理都在当前设备完成，文件不会上传。

## 打开应用

- **Web 版：**访问 <https://xanhiaoo.github.io/samsung-motion-photo-tool/>。建议使用较新的 Samsung Internet 或 Android Chrome。首次打开或更新后若页面异常，可刷新页面；仍未恢复时再清除站点缓存。
- **Android 版：**安装 APK 并打开应用。选择文件时会调用 Android 系统文件选择器；生成结果保存到相册的 `Pictures/Motion Photo Tool`。

首页有三种入口：**视频生成动态图**、**批量转换**和**照片 + 视频**。下方配图为标准手机视口截图；视频和照片+视频截图已滚动到主要编辑控件。

## 从视频生成动态图

适合截取一段视频，并从片段中挑选一帧作为封面。

1. 在首页点 **视频生成动态图**，选择 MP4 或 MOV 视频。
2. 在缩略图时间轴上调整选区两端以设置片段起点和终点；按住选区内部可整体左右移动片段。靠近素材边缘拖动时，时间轴会跟随扩展，便于连续调整。
3. 拖动 **拖动选择封面** 滑块，在已选片段内选择封面帧。
4. 点 **预览片段** 检查选段。默认勾选 **结束时渐变回封面**，**渐变时长**默认是 **0.5 秒**；可调整时长，或取消勾选关闭渐变。
5. 选择裁剪方式后点 **生成 Motion Photo**。
   - **快速裁剪：**直接复制原视频，通常更快；起点可能有少量偏差。
   - **精确裁剪：**重新编码 H.264，边界更准确，但处理更慢。
6. 生成完成后点 **保存 Motion Photo**。Android 版写入相册；Web 版下载文件。

如果不调整选段，默认使用完整视频。封面保存为 JPEG。启用结尾渐变时会优先只处理视频结尾的短过渡；Android 设备会尝试硬件加速，不兼容时可能回退到软件处理。

## 批量转换动态照片

适合一次导入多张已有的动态照片。每个文件需包含静态图片以及内嵌的 MP4 / MOV 视频。

1. 在首页点 **批量转换**。
2. 点 **选择动态图文件**，在系统选择器中多选 JPG / JPEG / HEIC 文件。也可以稍后点 **继续添加文件** 补充队列。
3. 等待应用逐个分析队列。普通静态图片或缺少内嵌视频的文件无法按此方式转换；请改用 **照片 + 视频**。
4. 查看每项状态：
   - **已是 Samsung Motion Photo：**文件已经是目标格式，可直接点该行的下载按钮保存。
   - **已识别图片和视频：**点该行的 **转换**，或用页面底部的 **全部转换** 顺序处理。
   - **无法解析 / 转换失败：**检查文件内容和格式；失败项会显示原因。
5. 转换完成后点对应下载按钮保存。可用 **清空列表** 移除当前队列。

批量模式默认启用 **结束时渐变回封面**，渐变时长初始为 **0.5 秒**；此设置应用于随后转换的文件。处理期间请保持页面打开。

## 照片 + 视频合成动态图

适合手动指定一张封面照片和一段视频。

1. 在首页点 **照片 + 视频**。
2. 点 **选择照片**，导入 JPG / JPEG / HEIC / PNG；此照片会用作 Motion Photo 封面。
3. 点 **选择视频**，导入 MP4 / MOV。
4. 如需让照片尺寸匹配视频，可启用 **图片自适应视频尺寸**。
5. 在时间轴调整视频片段起止位置；可拖动选区整体横移，并用 **预览片段** 检查效果。
6. **结束时渐变回封面**默认开启，渐变时长默认 **0.5 秒**。按需调整、关闭，或选择快速/精确裁剪。
7. 点 **生成 Motion Photo**，完成后保存结果。

未裁剪时使用完整视频。此模式没有单独的视频封面滑块，因为所选照片始终作为封面。

![照片与视频合成模式的选段、渐变和裁剪控件](images/manual-preview.png)

## 选择哪种方式

| 你的素材 | 选择 |
| --- | --- |
| 一段 MP4 / MOV，要从视频取封面 | 视频生成动态图 |
| 多个本身已内嵌视频的动态照片文件 | 批量转换 |
| 一张独立照片和一段视频 | 照片 + 视频 |

## 隐私、兼容性与常见问题

- 文件在本机读取和处理，不会上传；原始文件不会被覆盖。
- Android 输出位于相册 `Pictures/Motion Photo Tool`；Web 输出通过浏览器下载。
- Android 版最低支持 Android 10。较新的 Android System WebView 有助于正常运行 WebAssembly 和视频帧提取。
- **选中的动态照片没有进入批量队列：**确认选择的是含内嵌 MP4 / MOV 视频的动态照片，而非普通静态图。也可尝试先在系统图库确认原文件能播放。
- **选到照片或视频后无法预览：**尝试使用 JPEG 和 H.264 MP4；MOV 需要先转换，可能多花一些时间。
- **快速裁剪起点不够准：**改用 **精确裁剪**；它会重新编码，耗时更长。
- **处理似乎停住：**保持应用/标签页打开，不要切到会冻结页面的省电模式。长视频或 MOV 转换需要更多时间。
- **相册里没有结果：**检查 `Pictures/Motion Photo Tool`，或用系统文件管理器搜索最近保存的 `_MP.jpg` 文件。
- **生成的动态照片不能播放：**不同机型和图库对视频编码的支持不同；可改用 H.264 MP4、缩短片段后重新生成。
