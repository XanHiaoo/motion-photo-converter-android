# Motion Photo Tool 使用指南

Motion Photo Tool 用于把视频、动态图片或照片与视频转换为 Samsung Motion Photo。

所有处理都在当前设备完成，文件不会上传到服务器。

## 使用方式

### Web 版

打开在线预览：

<https://xanhiaoo.github.io/samsung-motion-photo-tool/>

建议使用较新的 Samsung Internet 或 Android Chrome。首次打开或更新版本后，如果页面显示异常，可以刷新页面或清除站点缓存。

### Android 版

安装 GitHub Release 中的 APK 后，直接打开应用即可。应用通过系统文件选择器读取文件，导出结果会保存到相册中的 Motion Photo Tool 目录。

## 三种功能

### 1. 视频生成动态图片

适合把一段视频制作成 Samsung Motion Photo。

1. 点击“视频生成动态图”。
2. 选择一个视频文件。
3. 设置开始和结束位置，或保留完整视频。
4. 从视频中选择封面帧。
5. 点击生成并保存结果。

快速裁剪速度更快，但起点可能受视频关键帧影响；需要更准确的起止位置时，选择精确裁剪。精确裁剪会重新编码视频，处理时间更长。

开启“结束时渐变回封面”后，应用通常只编码视频结尾的短过渡，并保留原视频主体；Android 版会优先尝试硬件编码。少数视频格式或设备不兼容时会改用完整编码，因此可能仍需较长时间。若不需要渐变，可以关闭该选项以加快生成。

### 2. 批量导入动态图

适合一次处理多个已有的动态图片文件。

1. 点击“批量导入动态图”。
2. 一次选择多个文件。
3. 等待文件逐个处理。
4. 查看处理结果并保存生成的文件。

处理过程中请保持页面打开，不要关闭浏览器或应用。

### 3. 照片和视频合成动态图

适合手动选择一张照片和一段视频进行合成。

1. 点击“照片和视频合成动态图”。
2. 选择照片。
3. 选择视频。
4. 根据需要开启“图片自适应视频大小”。
5. 点击合成并保存结果。

开启图片自适应后，照片会按视频的尺寸进行调整，减少照片与视频尺寸不一致造成的兼容问题。

## 文件和隐私

- 输入文件通过系统文件选择器导入。
- 转换过程在本机完成，不需要网络上传。
- 输出文件保存到设备相册。
- 原始文件不会被覆盖。

## 兼容性提示

- Android 版最低支持 Android 10（API 29）。
- 需要较新的 Android System WebView 才能正常运行 Web Worker、WebAssembly 和视频帧提取。
- 不同三星手机和相册版本对视频编码、HEIC 和 Motion Photo 的支持可能不同。
- 如果某个文件无法播放，可以尝试使用 MP4 视频、JPEG 照片，或改用精确裁剪重新生成。

## 常见问题

### 页面打开后没有内容

先刷新页面；如果仍然空白，使用浏览器的“清除站点数据”后重新打开在线地址。

### 导出的动态图在相册中不播放

请确认视频编码格式受设备支持，并尝试缩短视频或使用精确裁剪重新生成。

### 找不到导出的文件

请在系统相册中查看“Motion Photo Tool”目录，也可以使用系统文件管理器搜索最近生成的文件。
